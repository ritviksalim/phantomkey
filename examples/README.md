# PhantomKey Examples

Copy-pasteable configs and a sample interaction to get PhantomKey wired up to an MCP-capable agent.

| File | What it is |
|---|---|
| [`claude_desktop_config.json`](claude_desktop_config.json) | Config snippet for Claude Desktop (`mcpServers` entry) |
| [`cursor_config.json`](cursor_config.json) | Config snippet for Cursor 0.40+ |
| [`cline_config.json`](cline_config.json) | Config snippet for the Cline VS Code extension |
| [`sample_agent_session.md`](sample_agent_session.md) | A walkthrough of what a real agent conversation looks like |

For the full integration guide, see [`docs/mcp-integration.md`](../docs/mcp-integration.md).

> ⚠️ **Every example contains placeholder values** like `your-master-password-here` and `/Users/you/...`. Replace them before use. **Do not commit your real master password to any config file.**
